# Telegram Password Generator Bot

A Python-based Telegram bot that generates random passwords quickly and easily.

## Features

- **Password Generation:** Generates random 10-character passwords containing numbers and special symbols.
- **Welcome Message:** Greets users when they start the bot.
- **Greetings:** Responds to `/hello` and `/bye` commands.
- **Custom Text Repetition:** Repeats "he" a specified number of times using the `/heh` command.
- **Echo Function:** Automatically repeats messages sent by users.

## Technologies Used

- Python
- pyTelegramBotAPI
- Secrets Module

## Commands

| Command | Description |
|---|---|
| `/start` | Starts the bot |
| `/password` | Generates a random password |
| `/hello` | Sends a greeting |
| `/bye` | Sends a goodbye message |
| `/heh` | Repeats "he" multiple times |

## Installation

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Start the bot:

```bash
python main.py
```
